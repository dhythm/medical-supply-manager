# MEDIBASE — 医療材料・医薬品マスタ統合基盤

製品名を入力するだけで、AI が公的認可情報・メーカー情報を収集して商品マスタを自動生成する、医療機関向けの購買管理基盤です。商品登録の作業負担を削減し、共同購入・電子カルテ連携・需要インサイトまでを一つの基盤で扱うことを目指しています。

## 背景

- 病院の購買管理では商品登録作業が大きな負担となっており、作業負担の約 50% を占めるとも言われる
- 医薬品・医療材料は製品数・メーカー数が多く、医材の約 7 割が海外製品のため、病院側は仕入れ判断が難しく卸会社に依存しやすい
- 厚生労働省などの認可情報を活用したデータベースを整備し、電子カルテと連携できれば価値の高いサービスとなり得る

## 機能

| 画面 | 概要 |
| --- | --- |
| ダッシュボード | 登録工数とマスタ充足率の可視化 |
| AI 商品登録 | 製品名の入力から認可情報・メーカー情報を収集し、マスタを自動生成 |
| 商品マスタ | 医薬品・医療材料のデータベース |
| 共同購入・価格 | 共同購入による価格交渉と卸依存度の管理 |
| 電子カルテ連携 | 使用実績データの取り込み |
| データ提供基盤 | 匿名化・同意管理を前提としたデータ活用 |
| 顧客の声・展示会 | 現場要望の一元化 |

## 技術スタック

- [Next.js](https://nextjs.org/) (App Router) / React 19 / TypeScript
- [Tailwind CSS](https://tailwindcss.com/) v4
- [shadcn/ui](https://ui.shadcn.com/) (Base UI)

## 開発

パッケージマネージャーには `pnpm` を使用します。

```sh
pnpm install

# 開発サーバーの起動
pnpm dev

# ビルド
pnpm build

# Lint
pnpm lint
```

開発サーバー起動後、http://localhost:3000 でアクセスできます。
