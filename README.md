# MEDIBASE — 医療材料・医薬品マスタ統合基盤

医療機関の購買業務を支える商品マスタ基盤です。商品登録の負担削減を起点に、共同購入による価格交渉、電子カルテ連携、データガバナンスまでを一つの基盤で扱います。

## 背景

- 病院の購買管理では商品登録作業が大きな負担となっており、作業負担の約 50% を占めるとも言われる
- 医薬品・医療材料は製品数・メーカー数が多く、医材の約 7 割が海外製品のため、病院側は仕入れ判断が難しく卸会社に依存しやすい
- 厚生労働省などの認可情報を活用したデータベースを整備し、電子カルテと連携できれば価値の高いサービスとなり得る

## 機能

### 購買業務

| 画面           | ルート          | 概要                                                                       |
| -------------- | --------------- | -------------------------------------------------------------------------- |
| ダッシュボード | `/`             | 登録品目数、要確認品目、海外製比率、マスタ充足率と直近更新品目を表示       |
| 商品マスタ     | `/catalog`      | キーワード・カテゴリ・原産区分での検索と一覧表示                           |
| 商品登録       | `/catalog/new`  | 手入力、または製品名から取得した候補を補正して商品マスタへ登録             |
| 共同購入・価格 | `/group-buying` | 価格交渉案件の作成、施設別需要量の登録、卸からの見積比較と採用・妥結の記録 |

### 連携・活用

| 画面             | ルート      | 概要                                                             |
| ---------------- | ----------- | ---------------------------------------------------------------- |
| 電子カルテ連携   | `/emr`      | 施設ごとの接続設定（方式・連携方向・スケジュール）と同期実行履歴 |
| データガバナンス | `/insights` | データ資産の登録、分類・保管期間・レビュー期日の管理と監査ログ   |
| 顧客の声         | `/voice`    | 展示会・訪問などで得た要望の登録と対応ステータスの管理           |

商品登録は「手入力」と「AI 補完」の 2 つの方法を選べます。AI 補完の製品情報取得は現在ダミー実装で、外部の認可情報・メーカー情報との接続は未実装です。登録元は手入力・AI 補完のいずれかとして記録されます。

画面のデータは PostgreSQL に永続化されます。組織スコープは単一組織（コード `JONAN`）に固定されています。

## セットアップ

Node.js は `.node-version`（24.13.0）、パッケージマネージャーは `pnpm` を使用します。データベースの起動には Docker が必要です。

```sh
cp .env.example .env
pnpm install

# PostgreSQLの起動、マイグレーション適用、シード投入
pnpm db:up
pnpm db:deploy
pnpm db:seed

# 開発サーバーの起動
pnpm dev
```

起動後、http://localhost:3000 でアクセスできます。

## 開発

```sh
# 単体テスト
pnpm test

# 結合テスト（PostgreSQLが必要）
pnpm db:test:prepare
pnpm test:integration

# CIと同じ静的チェック（スキーマ検証、フォーマット、Lint、未使用コード、型、単体テスト、ビルド）
pnpm verify:static

# 静的チェックに結合テストを加えた全チェック
pnpm verify
```

GitHub Actions では、`verify:static` の各チェックを並列に実行し、加えて PostgreSQL サービスコンテナ上で結合テストを検証します。
